# AI Recommender Implementation

Complete AI-powered recommendation system for dealflow screening.

## Overview

The AI Recommender analyzes all screening data (AI-generated and human input) to produce a 0-100 recommendation score with actionable thresholds.

## Features Implemented

### 1. Database Schema
**File**: `supabase/migrations/009_ai_recommendations.sql`

Creates `ai_recommendations` table to store:
- Deal ID (unique per deal)
- Score (0-100)
- Recommendation text
- Detailed rationale
- Full analysis data (JSON)
- Generated by user ID
- Timestamp

**RLS Policies**:
- Internal roles can view recommendations
- Dealflow managers can create/update recommendations

### 2. Edge Function
**File**: `supabase/functions/ai-recommend-deal/index.ts`

**Analyzes**:
- Startup profile (name, sector, description, team, traction)
- Deal terms (round type, target amount, valuation, instrument)
- Screening scores (all 7 criteria with notes)
- Screening review (overall score, decision, summary memo)
- Green flags and red flags

**Returns**:
- Score 0-100
- One-sentence recommendation
- Detailed rationale (200-300 words)

**Score Thresholds**:
- **0-39**: Strong Reject (critical issues, not investment-ready)
- **40-59**: Reject or Request More Information (significant concerns)
- **60-79**: Deep Dive Required (promising but needs validation/SME advice)
- **80-100**: Recommend to IC (strong opportunity, ready for investment)

### 3. UI Components
**File**: `app/app/deals/[id]/page.tsx`

**AI Recommender Button**:
- Located next to "AI Screen Pitch Deck" button
- Enabled only when screening data exists (memo + criteria filled)
- Calls edge function to generate recommendation
- Shows loading state while processing

**Recommendation Meter Display**:
- Visual progress bar with color-coded gradient
- Score display (large, color-coded number)
- Threshold indicators (shows which range applies)
- Recommendation text with color-coded background
- Collapsible detailed rationale section

**Color Coding**:
- Red (<40): Reject
- Yellow (40-59): Request More Info
- Orange (60-79): Deep Dive/SME Advice
- Green (80+): Recommend to IC

## Installation Steps

### Step 1: Apply Database Migration

Go to **Supabase Dashboard → SQL Editor** and run the following SQL:

```sql
-- AI Recommendations Table
-- Stores AI-generated recommendation scores for deals

CREATE TABLE IF NOT EXISTS ai_recommendations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  deal_id UUID NOT NULL REFERENCES deals(id) ON DELETE CASCADE,
  score INTEGER NOT NULL CHECK (score >= 0 AND score <= 100),
  recommendation_text TEXT NOT NULL,
  rationale TEXT NOT NULL,
  analysis_data JSONB,
  generated_by_user_id UUID REFERENCES profiles(id),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(deal_id)
);

-- Enable RLS
ALTER TABLE ai_recommendations ENABLE ROW LEVEL SECURITY;

-- Internal roles can view recommendations
CREATE POLICY "Internal roles can view recommendations" ON ai_recommendations
  FOR SELECT USING (
    EXISTS (
      SELECT 1 FROM profiles
      WHERE id = auth.uid()
      AND role IN ('admin', 'dealflow_manager', 'ic_member', 'ic_chair')
    )
  );

-- Dealflow managers can manage recommendations
CREATE POLICY "Dealflow managers can manage recommendations" ON ai_recommendations
  FOR ALL USING (
    EXISTS (
      SELECT 1 FROM profiles
      WHERE id = auth.uid()
      AND role IN ('admin', 'dealflow_manager')
    )
  );

-- Create index for faster lookups
CREATE INDEX idx_ai_recommendations_deal_id ON ai_recommendations(deal_id);
```

### Step 2: Deploy Edge Function

The edge function is already created at `supabase/functions/ai-recommend-deal/index.ts`.

Deploy it using:
```bash
npx supabase functions deploy ai-recommend-deal
```

**Important**: Make sure `ANTHROPIC_API_KEY` is set in your Supabase edge function secrets:
```bash
npx supabase secrets set ANTHROPIC_API_KEY=your_key_here
```

### Step 3: Test the Feature

1. Go to any deal in screening phase
2. Use "AI Screen Pitch Deck" to populate screening scores and memo
3. Click "AI Recommender" button
4. View the recommendation meter with score and rationale

## User Workflow

### Dealflow Manager Workflow

1. **Upload pitch deck** to deal
2. **Click "AI Screen Pitch Deck"** → AI analyzes deck and fills in:
   - All 7 criteria scores with detailed notes
   - Executive summary memo
3. **Click "YC Flags"** (if available) → AI detects:
   - Green flags (positive signals)
   - Red flags (warning signs)
4. **Review and adjust** AI suggestions manually if needed
5. **Click "AI Recommender"** → AI synthesizes everything and provides:
   - 0-100 recommendation score
   - Color-coded threshold indicator
   - Action recommendation (Recommend/Deep Dive/More Info/Reject)
   - Detailed rationale explaining the score
6. **Make final decision** based on comprehensive AI analysis

### What the AI Recommender Analyzes

The AI Recommender is the **final synthesis step** that considers:

✅ **All AI-generated content**:
- Pitch deck analysis (from AI Screen)
- Criteria scores and notes
- Green/red flags

✅ **All human input**:
- Manual adjustments to scores
- Custom notes and observations
- Overall screening decision
- Executive summary memo

✅ **Business fundamentals**:
- Startup profile and sector
- Team and traction
- Deal terms and valuation
- Market opportunity

The AI then provides an **objective, data-driven score** with clear reasoning.

## Technical Details

### Edge Function Flow

1. **Authentication**: Verify user is dealflow manager or admin
2. **Data Collection**: Fetch all screening data from database
3. **Prompt Construction**: Build comprehensive analysis prompt
4. **Claude API Call**: Send to Claude Sonnet 4.5 for analysis
5. **Response Parsing**: Extract score, recommendation, and rationale
6. **Database Storage**: Upsert recommendation (replace if exists)
7. **Return Result**: Send to frontend for display

### API Response Format

```json
{
  "success": true,
  "score": 75,
  "recommendation": "Deep dive required - Request SME validation before IC submission",
  "rationale": "The startup shows strong technical fundamentals with a score of 4.2/5 on team quality and 4.0/5 on innovation potential. However, market validation concerns (score 2.8/5) and competitive positioning questions warrant deeper investigation. The $5M valuation appears reasonable given current traction (200K MRR), but the path to profitability needs clearer articulation. Red flags around regulatory compliance require expert review before proceeding to IC. With proper SME validation in these areas, this could become a strong IC candidate."
}
```

### Performance Considerations

- **Caching**: Recommendations stored in database, regenerate only when needed
- **Token Usage**: ~1500 tokens per recommendation (efficient prompt design)
- **Response Time**: 3-5 seconds typical (Claude API latency)
- **Cost**: ~$0.015 per recommendation (using Claude Sonnet 4.5)

## Color-Coded Thresholds Explained

### 🔴 Red Zone (0-39): Reject
**Meaning**: Critical issues make this unsuitable for investment
**Action**: Reject the deal
**Common Reasons**:
- Fundamental business model flaws
- Severe team capability gaps
- Insurmountable market barriers
- Multiple critical red flags

### 🟡 Yellow Zone (40-59): Request More Info or Reject
**Meaning**: Significant concerns but some potential
**Action**: Request clarification or additional information, likely reject
**Common Reasons**:
- Incomplete information in key areas
- Moderate concerns across multiple criteria
- Unclear value proposition
- Market validation needed

### 🟠 Orange Zone (60-79): Deep Dive Required
**Meaning**: Promising opportunity but needs validation
**Action**: Conduct deeper analysis, consult subject matter experts
**Common Reasons**:
- Strong fundamentals with specific gaps
- Technical validation needed
- Market dynamics require expert assessment
- Competitive analysis needed

### 🟢 Green Zone (80-100): Recommend to IC
**Meaning**: Strong investment opportunity
**Action**: Present to Investment Committee
**Common Reasons**:
- Excellent team and execution
- Clear market opportunity
- Strong traction and metrics
- Favorable deal terms
- Minimal red flags

## Troubleshooting

### Button is Disabled
**Cause**: Missing screening data
**Solution**: Ensure you've completed AI screening and have a summary memo

### Edge Function Error
**Cause**: Missing ANTHROPIC_API_KEY or network issue
**Solution**: Set edge function secret and check Supabase logs

### Recommendation Not Displaying
**Cause**: Database query permissions or missing data
**Solution**: Check RLS policies and verify recommendation was saved

### Wrong Score Range
**Cause**: AI response parsing failed
**Solution**: Check edge function logs for parsing errors
